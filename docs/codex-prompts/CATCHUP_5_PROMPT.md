# Catch-up phase 5 prompt — кликабельные группы и преподаватели в расписании

```text
Прочитай AGENTS.md, CLAUDE.md, docs/PROJECT_MAP.md и docs/CATCHUP_PLAN.md.

Контекст.
Бэкенд добавил в расписание идентификаторы справочника, чтобы из карточки пары
можно было провалиться в чужое расписание. Локальные копии для сверки:
бэк — /home/sakura/backend/app/schemas/schedule_schemas.py,
веб-фронт — /home/sakura/frontend (коммит "Кликабельные преподаватели и группы
в расписании" и "Возврат к своему расписанию — плашка снизу вместо крестика").

Контракт:
- LessonSchema.lecturer_oid: str | null
- AudienceSchema.members: list[{ label, name, oid }] — те же группы поштучно.
  label — как показать ("ПИ41б/1"), name — имя в справочнике ("ПИ41б"),
  oid — идентификатор. Готовая строка audience.label осталась на месте.
- oid == null означает "этой сущности нет в справочнике, тап не нужен".

Задача.
1. Слой данных: добавь lecturerOid в ScheduleLessonDto и members в
   ScheduleAudienceDto (data/network/dto/ScheduleDtos.kt), прокинь их через
   data/schedule/ScheduleMappers.kt в Lesson и LessonAudience
   (ui/main/schedule/ScheduleModels.kt). members по умолчанию — пустой список,
   чтобы старые ответы не ломали разбор.
2. UI карточки пары: преподаватель и каждая группа из members с непустым oid
   становятся кликабельными. Группы рендерятся поштучно вместо готовой строки
   label, когда members не пуст; когда пуст — прежний фолбэк на audience.label.
   Элементы без oid выглядят как обычный текст и не реагируют на тап.
3. Тап открывает расписание этой сущности. У ScheduleViewModel уже есть выбор
   группы и преподавателя через пикер и per-tab in-memory кэш — переиспользуй
   этот же путь, не заводи параллельный.
4. Пока показывается чужое расписание — плашка внизу экрана "вернуться к
   своему" (в вебе крестик заменили именно на неё). Возврат сбрасывает выбор
   на сущность владельца токена, то есть на запрос без параметра group.
5. Не ломай уже реализованное: автоскролл к текущему дню, ленивую догрузку
   до двух дополнительных недель (ScheduleUiState.MAX_EXTRA_WEEKS), скелетоны
   и ретраи.

Ограничения.
- Сетевых вызовов внутри композаблов нет.
- @Preview для затронутых компонентов, независимые от сети.
- Тексты интерфейса — на русском, в res/values/strings.xml.

Проверка.
./gradlew :app:compileStagingDebugKotlin

После изменений обнови docs/PROJECT_MAP.md.
```
